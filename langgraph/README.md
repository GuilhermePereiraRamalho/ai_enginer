# LangGraph

Esta pasta reúne meus estudos e exercícios de um curso sobre LangGraph. Os notebooks apresentam a criação de fluxos com nós, transições e decisões condicionais, incluindo exemplos que usam modelos de linguagem.

O material é didático e pode ser ajustado para acompanhar as versões atuais das bibliotecas. Configure as chaves de API localmente e não as inclua nos commits.
