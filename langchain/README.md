# LangChain

Esta pasta reúne meus estudos e exercícios de um curso sobre LangChain. Os notebooks exploram conceitos como prompts, modelos de linguagem, chains, ferramentas, agentes, embeddings e busca semântica. Também há exemplos de integração com o Pinecone e uma aplicação simples com Streamlit.

O material é didático e pode ser ajustado para acompanhar as versões atuais das bibliotecas. Configure as chaves de API localmente e não as inclua nos commits.
