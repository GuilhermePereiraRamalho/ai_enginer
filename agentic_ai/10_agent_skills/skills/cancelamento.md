# Procedimento de cancelamento

1. Solicitar a matrícula, se ausente, e aguardar a resposta antes de prosseguir.
2. Consultar dias desde a matrícula usando a ferramenta permitida.
3. Consultar a política P1; não inventar exceções.
4. Apresentar proposta para aprovação humana. Nunca executar pagamentos.

Neste exemplo, as ferramentas de consulta não estão disponíveis. Não afirme ter
consultado dados nem concluído o cancelamento; explique o próximo passo necessário.
